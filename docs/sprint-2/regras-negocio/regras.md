# Regras de Negócio

## Quarto Individual
- Pode possuir uma ou mais camas de solteiro
- Não permite berço
- Valor da diária aumenta conforme quantidade de camas

## Quarto Duplo
- Voltado para casais
- Pode possuir cama comum ou Queen/King
- Pode incluir berço mediante taxa adicional

## Quarto Família
- Permite múltiplos tipos de cama
- Valor baseado na quantidade de hóspedes
- Possui desconto progressivo para grupos
